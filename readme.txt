A production-ready WordPress plugin to easily integrate AI chatbots (OpenAI, Gemini, Anthropic) into your website.

== Description ==

AI Chatbot Plugin allows you to add a floating AI chatbot widget to your WordPress site with zero coding. 
Connect to your preferred AI provider (OpenAI, Google Gemini, or Anthropic), configure the chatbot's system prompt, 
customize its appearance to match your brand, and you are ready to go.

### Features
* **Multiple AI Providers:** Choose from OpenAI, Google Gemini, or Anthropic.
* **Fully Customizable:** Change colors, icons, and positioning.
* **Secure:** API keys are never exposed to the frontend.
* **Lightweight:** Built with Vanilla JS and CSS for maximum performance.
* **No Code Required:** Simple settings page to configure everything.

== Installation ==

1. Upload the `ai-chatbot-plugin-for-wordpress` folder to the `/wp-content/plugins/` directory, or upload the zip file directly via the WordPress admin dashboard.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to the new 'AI Chatbot' menu in the admin dashboard.
4. Enter your API key and configure your chatbot settings.

== Frequently Asked Questions ==

= Where do I get an API key? =
You can obtain an API key directly from the provider you wish to use (e.g., platform.openai.com, Google AI Studio, or Anthropic Console).

= Can I use a custom model? =
Yes, you can specify the exact model name you wish to use in the plugin settings.
